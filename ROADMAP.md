# Roadmap

## Next: extend trustworthy imports and linkage

- Add recent FEL/MEME versions only after pinning nonpathogenic authoritative output fixtures, checking header changes, site test-status semantics, diagnostics, bootstrap/asymptotic support distinctions, and any native corrections.
- Design and validate an analysis-time provenance bundle binding each original result to alignment-content hashes, taxa, genetic code, masking, and coordinate transformations. Verify supplied alignment content and maps before linking native analyses. Document what is cryptographically verified and what relies on trusted producer metadata.
- Preserve per-file method scope and settings in linked views; never infer selected branch–site intersections by combining independent calls.
- Validate Contrast-FEL branch-group and pairwise/omnibus contrast headers, group estimates and native multiplicity adjustments using authoritative, nonpathogenic fixtures. Distinguish differences from positive selection and do not label differences as timed shifts.

## Further evidence views

- **FUBAR:** native posterior probabilities for purifying/diversifying selection and MCMC diagnostics; separate posterior thresholds from likelihood-test p-values.
- **aBSREL:** tree annotations carrying native branch-level tests and method-native corrected p-values. No fabricated site localization.
- **RELAX:** test/reference group comparisons, the relaxation/intensification parameter and model tests. Do not reinterpret relaxation as sitewise positive selection.
- **Recombination-aware views:** preserve each partition's tree, tested scope, site coverage and coordinate map; validate overlap, omitted sites, and joint display semantics before accepting partitioned imports.

## Usability and engineering

- Project save/restore with original data, validated provenance, thresholds, and selection state.
- Adaptive track density and large-file performance benchmarks; streaming or workers if demonstrated necessary.
- Broader Firefox/Safari verification, screen-reader audit, and vector-export typography checks.
- Calibrated uncertainty/fit-diagnostic displays when upstream output supports them. Do not manufacture uncertainty from absent diagnostics.
- Reproducible publication bundles with evidence table, SVG and original settings/provenance.

No deployment, repository visibility change, or license decision is included in this roadmap's implementation work.
